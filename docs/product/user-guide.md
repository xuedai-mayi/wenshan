## 1. 安装与首次启动

### 需要什么

- Node.js 22.19+（推荐 24）
- pnpm（只在安装阶段用）：`npm install -g pnpm`
- Python 3.11（可选）：只影响 PDF / Word / 录音 / GIS 提取；纯文本与问答不需要
- 桌面浏览器：Chrome / Edge / Safari 桌面版，窗口 ≥ 1280×800（1.0 只面向 PC Web，不做手机端适配）

### 三步启动

```bash
git clone https://github.com/xuedai-mayi/wenshan.git
cd wenshan
npm start
```

首次运行会问「现在开始安装？」，回车即可（等价 `npm run setup`）。安装要构建内置运行时，通常 3—8 分钟，只做一次。

装完后服务会打印入口地址并在就绪后自动打开浏览器：

| 页面 | 地址 |
| --- | --- |
| 主界面 | `http://127.0.0.1:3080/` |
| 知识图谱 | `http://127.0.0.1:3080/wenshan/knowledge-graph` |
| 照片地图 | `http://127.0.0.1:3080/wenshan/photo-map` |
| 知识星系 | `http://127.0.0.1:3080/wenshan/knowledge-galaxy` |

想当成常驻命令用：`npm link` 之后在任意目录敲 `wenshan`。

> 端口被占用时自动顺延并打印实际地址；也可以 `npm start -- --port 3081`。

### 先做一次体检

```bash
npm run doctor
```

会逐项列出 Node、pnpm、Python、运行时、页面依赖、数据、端口、挂载层。阻塞项会直接告诉你缺什么、跑哪条命令补。

## 2. 配置模型

进入主界面 → **设置 > 模型** → 选择模型提供方并填入 API Key。

要点：

- 凭据写在本机 `.wenshan-home/`，不进入仓库、不随资料上传。
- 上传资料后的自动抽取、对话问答都用**这里选中的模型**，不需要另外配一套环境变量。
- 切换模型后，已生成的草稿不会重算；要重算就重新触发构建（见第 10 节）。

## 3. 收录资料

切换到 **知识演化** 模式，然后任选一种：

- 点 **选择实习资料总文件夹**，选一个目录；系统只收可识别的文件，递归子目录。
- 在对话里直接粘贴短文本。

点 **收录并生成图谱** 后，文件逐个上传。按内容 SHA-256 去重：同一份文件重复收录不会产生重复来源。

### 支持格式

| 类型 | 格式 | 备注 |
| --- | --- | --- |
| 文字 | TXT、Markdown、CSV、TSV | 直接读 |
| 文档 | PDF、DOCX | 需要 Python 提取链 |
| 图片 | JPG、PNG、WebP、HEIC、TIFF | 原件保存，正文由视觉模型识读 |
| 录音 | MP3、WAV、M4A、OGG、FLAC、AAC | 需要录音依赖组，缺了就降级 |
| GIS | GeoJSON、GPX、含 Shapefile/GDB 的 ZIP | 抽出要素、坐标与属性 |

单文件默认上限 200 MB。

### 上传之后会发生什么

1. 原件、提取文本、结构化结果分别落盘（`data/knowledge/`）。
2. 正文 ≥ 200 字时，后台自动开始抽取：按小节切块（默认 2500 字/块，最多 60 块、超出等距抽样），逐块调用当前模型抽取七类节点：讲解点 / 地点 / 概念 / 物种 / 气象 / 每日 / 主线。
3. 合并去重、与基础图谱对账：同名同类节点不重复新建，列入「待补充」交给你判断。
4. 产出**待审核草稿**——不会自动进正式知识库。

上传接口先返回，构建在后台跑；进度见 `GET /wenshan/api/evolution/build`，也可以在知识图谱页看到草稿节点。

> 抽取是生成式的：同一份资料两次跑出来的节点数会不一样。这不是 bug，是「发布前必须人工核对」的理由。

## 4. 审核与发布

在 **知识演化** 对话里发送：

```text
处理最新资料
```

引擎读取来源并生成草稿。逐条核对标题、正文、关系、坐标，觉得可以了就发送完整口令：

```text
确认发布 draft-xxxxxxxx
```

- 必须带上草稿 id；「可以」「继续」「发布吧」都不会触发。
- 发布后检索引擎立即更新，野外助教马上能查到。
- 不满意就驳回（保留审计，不删除记录）。

发布门禁在存储层强制，不依赖提示词自觉。

## 5. 现场问答

切换到 **野外助教** 模式。这个模式只有只读工具，不能改资料、不能建草稿、不能发布。

可以这样问：

- 「三叠泉的阶梯状跌水是怎么形成的？」
- 「锦绣谷附近讲了什么？」
- 「含鄱口到五老峰今天的行程怎么安排？」
- 「昨天下午的天气对讲解有什么影响？」

回答会带来源（讲解点 / 概念 / 每日记录）。三路检索（词法 + 图谱 + 空间）在 152 题评测上的表现：Hit@1 91.4%，Hit@5 96.1%。

## 6. 知识缺口闭环

当野外助教确认「已发布资料中未覆盖此问题」，它会：

1. 明确告诉你未覆盖，而不是编一个答案；
2. 把问题原话登记为知识缺口；同一问题重复被问只累计次数。

查看缺口：

- 知识图谱页左侧 **待补充问题** 面板；
- 或在知识演化对话里发送 `查看知识缺口`。

补料流程：按被问次数排序 → 补对应资料 → 重新构建 → 发布 → 让知识演化引擎逐条销掉缺口。

## 7. 图谱、照片地图与知识星系

**知识图谱**（`/wenshan/knowledge-graph`）：搜索、按类型筛选、拖动、点节点读正文；草稿、资料、待补问题都在这一页。

**照片地图**（`/wenshan/photo-map`）：照片按讲解点聚簇落在真实地形晕渲底图上，支持逐日路线动画与「回放全程」。底图由 `npm run terrain` 生成，一次生成后离线可用；缺底图时自动退回矢量底图。

**知识星系**（`/wenshan/knowledge-galaxy`）：三维视图，节点按类型发光、关联线粒子流动，可旋转、聚焦、读节点正文。

## 8. 备份、恢复与换机

```bash
npm run backup                                  # 写入 backups/
npm run backup ~/wenshan-backups --data-only    # 只备份知识库，不含模型凭据
npm run restore backups/wenshan-backup-YYYYMMDD-HHmmss.wenshan.gz
npm run restore <文件> --dry-run                # 只校验，不写盘
```

规则：

- 备份内容 = `data/knowledge/`（知识、原件、结构化结果、事件日志）+ `.wenshan-home/`（会话与模型凭据）。
- 归档自带清单、大小、权限与 SHA-256，恢复时逐条校验；路径白名单只允许上面两处。
- 恢复前会先把现状复制成 `<目录>-restore-<时间戳>`，恢复错了能退回来。
- 默认归档**含 API Key**：不要提交仓库、不要放公共网盘；给别人用就加 `--data-only`。

换机器：新机器装好后执行 `npm run restore <归档>`，再 `npm start`。

## 9. 换一条实习线

1. 复制 `config/lushan.json` 为 `config/<你的站点>.json`，改数据源路径、图层映射、文案。
2. 用原始 GDB / 知识库重建基础数据：

```bash
npm run data -- config/<你的站点>.json
```

3. 启动时让挂载层指向新数据（按你的部署方式改 `config/wenshan.yml` 的 `dataDir` 与站点配置）。
4. 跑 `npm run doctor` 确认数据齐全，再 `npm start`。

## 10. 常见操作与故障处理

| 现象 | 处理 |
| --- | --- |
| 页面打不开 | `npm run health` 看服务是否活着；不行就 `npm run doctor` |
| 上传后没有草稿 | 正文 < 200 字会跳过；或模型没配 Key——构建状态里会直说 |
| 想要重跑某份资料 | `POST /wenshan/api/evolution/build {"sourceIds":["src-…"],"force":true}` |
| 抽取结果太散/太密 | 改 `config/wenshan.yml` 里 `build.maxChars` / `maxChunks` / `concurrency` |
| PDF/录音/GIS 提取失败 | `npm run doctor` 看缺哪组 Python 依赖；`npm run setup --force` 重装 |
| 照片地图没有底图 | `npm run terrain` |
| 端口被占 | `npm start -- --port 3081`，或 `--port 0` 让系统分配 |
| 想清空重来 | 删掉 `.wenshan-home/` 重置运行状态；删 `data/knowledge/` 清空后加知识（先备份） |
| 升级后行为异常 | 先 `npm run setup --force` 重建运行时，再 `npm run doctor` |

更多问题见 [FAQ](faq.md)。
