# 问山 · FAQ

## 安装与运行

**没有 Python 能用吗？**
能。纯文本（TXT/MD/CSV）、GeoJSON/GPX 的收录，问答、图谱、地图、星系都不需要 Python。PDF、DOCX、录音、Shapefile/GDB 的提取依赖 Python 3.11 与项目内 `.venv`；缺了只会降级对应格式，不会拖垮整体。

**支持手机或平板吗？**
1.0 只面向桌面 Web：Chrome / Edge / Safari 桌面版，窗口 ≥ 1280×800。窄屏能打开、能问答，但不做适配与验收；现场建议用笔记本或平板横屏。原生 App、小程序与离线缓存不在 1.0 范围内。

**Windows / macOS / Linux 都支持吗？**
是。只有一个入口 `bin/wenshan.mjs`，没有平台专用脚本。Windows 在 PowerShell 或 cmd 里 `npm start` 即可；`npm link` 之后可在任意目录敲 `wenshan`。

**为什么端口有时候不是 3080？**
默认 3080，被占用时自动顺延到下一个空闲端口并打印实际地址。想固定：`npm start -- --port 3081`；想让系统分配：`--port 0`。

**首次启动卡在安装？**
安装要构建内置运行时，通常 3—8 分钟。看日志有没有卡在 `pnpm install` 或 `pnpm build`；国内网络可以给 pnpm 配镜像后重跑 `npm run setup -- --force`。

**怎么彻底卸载？**
删除仓库目录即可。想保留知识库就先 `npm run backup --data-only`。没有写系统目录，也没有注册全局服务（除非你自己 `npm link` 或装了 systemd 单元）。

## 数据与隐私

**我的资料和 API Key 存在哪里？**
- 资料与知识：`data/knowledge/`（原件 `sources/`、提取 `extracted/`、结构化 `structured/`、事件 `events.jsonl`）。
- 会话、凭据、profile 层：`.wenshan-home/`（可用 `WENSHAN_HOME` 改）。
- 两者都在 `.gitignore` 里，不进仓库。

**会往外部发数据吗？**
只有一件事会出网：调用你在「设置 > 模型」里选的模型提供方，把待抽取的文本或问答上下文发过去。没有遥测、没有统计上报、没有自动更新检查。要完全离线，就换成本地模型提供方。

**备份文件里有什么？**
默认 = 知识库 + 运行状态（含 API Key）。交给别人或放网盘时用 `npm run backup --data-only`，只带知识库。归档目录请保持 700 权限。

**照片里有学生人像，能公开发吗？**
公开仓库或对外演示前，必须自行确认人像、论文、地图数据的授权与隐私边界。`data/photos/`、`data/knowledge/` 默认不进 git 就是为此。

## 知识与抽取

**为什么同一份资料两次抽取的节点数不一样？**
抽取是生成式的，`temperature` 只能压幅度、不能保证复现（实测同一份 1582 字资料两次为 13 和 18 个节点）。所以设计上强制人工审核 + 口令发布，而不是自动入库。

**草稿能自动发布吗？**
不能，这是刻意的。发布必须在存储层收到完整口令 `确认发布 draft-xxxxxxxx`。要批量处理就人工逐条确认，别想着绕过。

**答不上来的问题去哪了？**
登记为知识缺口（`open`），带被问次数。在图谱页左侧「待补充问题」或对话里 `查看知识缺口` 查看；补料发布后逐条销账。

**会不会一本正经地胡说？**
风险存在，产品用三道闸压它：回答必须带检索来源；未覆盖时明确说「未覆盖」并登记缺口；知识只在人工发布后才进入检索。评测只是检索质量（152 题 Hit@1 91.4%），不等于生成质量，别把评测数字当成「不会错」的保证。

**支持哪些模型？**
用运行时「设置 > 模型」里可选的那些提供方与模型；问山不绑定特定厂商，也不额外读环境变量里的 Key。

**上传有大小限制吗？**
单文件默认 200 MB（挂载层 `maxUploadBytes`），单份提取文本上限 200 万字。超了请拆分。

## 多人使用与部署

**能几个人同时用吗？**
本机服务本身没有账号体系，适合一台机器（教师笔记本 / 现场内网服务器）多人通过浏览器访问。需要区分身份与权限，请在前面加反向代理与登录（见 [部署指南](../deploy.md)），或等 1.1 的账号与角色。

**能部署到公网吗？**
可以，但不要直接暴露端口。默认只监听 `127.0.0.1`；公网必须走反向代理做 TLS、登录、请求体积限制，并用 `--trusted-host <你的域名>` 让浏览器信任栅栏接受该域名。完整清单见 [部署指南](../deploy.md)。

**Docker 镜像多大？**
预装了内置运行时与 Python 提取链，属于「重但开箱即用」。想更小就基于同一 Dockerfile 去掉音频/ GIS 依赖组。

**怎么升级？**
拉新代码 → `npm run setup -- --force` → `npm run doctor` → 重启。升级前先 `npm run backup`。知识事件是 append-only 的，重放不会丢人工审核成果。

## 评测与可信度

**152 题评测是怎么来的？**
从知识库自动构建：概念定义 89 题、讲解中心 26 题、空间 37 题；对比纯词法、加图谱、加空间三种配置。报告与图表在 `docs/evaluation/`，复现命令 `npm run eval`。

**能换一条实习线吗？**
能。复制 `config/lushan.json` 改成你的站点配置，`npm run data -- config/<站点>.json` 重建基础数据，再改挂载层的 `dataDir`。见用户手册第 9 节。

**许可证是什么？**
MIT。随包分发的运行时同样是 MIT，第三方声明见 [NOTICE.md](../../NOTICE.md)。庐山示例数据的授权与隐私边界请自行确认后再公开使用。
